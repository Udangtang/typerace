# Word Drop — 공용 랭킹 보드 버전

하늘에서 떨어지는 단어를 바닥에 닿기 전에 타이핑하는 어휘 게임입니다.
- 한국어: 교과서 어휘 75개
- 영어: 45개
- 맞힌 단어마다 뜻 · 예문 · 한 칸 만화 카드가 나옵니다.

## 구조

```
index.html                     게임 전체 (화면 · 단어 데이터 · 만화 렌더러)
netlify/functions/scores.mjs   랭킹 API  (/api/scores)
netlify.toml                   Netlify 빌드 설정
package.json                   의존성 (@netlify/blobs)
```

랭킹은 Netlify Blobs에 `scores-v1` JSON 파일 하나로 저장됩니다. 도감과 개인 최고 점수는 각자의 브라우저에 저장됩니다.

## 배포

1. **이 파일들이 저장소 맨 위(루트)에 오도록** GitHub 저장소에 올립니다.
   - `word-drop/` 폴더째 올렸다면 Netlify의 **Base directory**를 `word-drop`으로 지정하세요.
2. Netlify에서 저장소를 연결하고 **Deploy**합니다.
   - 빌드 설정은 `netlify.toml`이 채웁니다.
3. 배포 화면에 **Functions: scores**가 보이면 정상입니다.
   - `https://<사이트>/api/scores`를 열면 `{"records":[]}`가 나와야 합니다.
4. (선택) 환경 변수 `ADMIN_TOKEN`을 넣고 다시 배포합니다.
   - 이후 `https://<사이트>/?admin=1`로 접속하면 랭킹 기록 옆에 삭제 버튼이 나타납니다.

## 랭킹 규칙

- 언어별로 따로 순위를 매기고, 같은 닉네임은 최고 기록 1개만 순위에 올라갑니다.
- 서버가 타당성을 검사해서 비정상 기록은 받지 않습니다.
  - 점수가 단어 수에 비해 너무 높은 경우
  - 단어당 0.4초 미만으로 잡은 경우
  - 콤보·웨이브가 맞지 않는 경우
- 로그인이 없는 공개 게임이라 같은 닉네임을 누구나 쓸 수 있습니다. 이상한 기록은 관리자 모드에서 지우세요.
- 서버에 연결할 수 없으면 이 브라우저에만 저장하는 오프라인 모드로 동작합니다.
  - 랭킹 보드 아래 상태 점: 초록 = 공용, 주황 = 오프라인
